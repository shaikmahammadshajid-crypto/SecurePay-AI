SecurePay AI Reviewer Guide

This page explains the main task, how to test the project, and what features to present during final review.

Main Task of the Project

SecurePay AI detects potentially fraudulent credit card transactions using a trained machine-learning model. It accepts transaction features, predicts fraud or genuine, calculates fraud probability, assigns risk level, recommends action, and stores the result for audit.

Problem Statement

Credit card fraud is rare but financially harmful. Manual checking is slow, and accuracy alone is misleading because genuine transactions heavily outnumber fraud cases. This project provides an AI-based triage workflow.

Proposed Solution

A Flask web app on Render uses Random Forest classification, StandardScaler preprocessing, SQLite history, PDF reporting, authentication, batch screening, admin monitoring, and AI assistant commands.

Reviewer Demo Flow

1. Create a user account or login 2. Open Predict and use a demo transaction 3. Submit prediction and explain probability/risk 4. Open History to show audit storage 5. Open AI Assistant and run health, summary, or report command 6. Show /health endpoint and Render deployment

Key Features to Present

Authentication, single prediction, batch CSV screening, AI recommendations, history, profile, admin dashboard, audit PDF, health check, Flask/Gunicorn Render deployment, and pytest validation.

Important Accuracy Note

The project does not claim impossible 100% model accuracy. It uses measurable ML evaluation concepts such as precision, recall, F1 score, ROC-AUC, and confusion matrix through the training script.
