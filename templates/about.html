About SecurePay AI

SecurePay AI is now a Flask application deployed directly on Render. It uses a trained Random Forest model, SQLite audit storage, bcrypt authentication, batch inference, and assistant-driven operational workflows.

Model

Random Forest classifier with 30 transaction signals: Time, V1-V28, and Amount.

Predictions return a fraud/genuine label, probability, risk level, and operational recommendation.

Render Runtime

The production process is Gunicorn serving Flask. Render builds dependencies from requirements.txt and starts app:app.

Health checks run through the /health endpoint.
